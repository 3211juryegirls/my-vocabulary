# My Vocabulary

## 실행
1. ZIP을 압축 해제합니다.
2. `index.html`을 Chrome, Edge 등 최신 브라우저에서 엽니다.
3. 왼쪽 메뉴 위의 Learning language에서 언어를 바꾸거나 `＋` 버튼으로 언어를 추가합니다.

별도 설치, 서버, AI API, 인터넷 연결이 필요하지 않습니다. 글꼴은 온라인 연결 시 Google Fonts를 사용하고, 오프라인에서는 시스템 글꼴로 대체됩니다.

## 데이터 저장 및 백업
- 데이터는 브라우저의 LocalStorage에 저장됩니다.
- Settings → Export JSON에서 전체 언어·단어·단어장·학습 기록·오답·목표·보상 데이터를 백업합니다.
- Import JSON에서 `merge`는 기존 데이터에 추가하고, `replace`는 현재 데이터를 백업 파일 내용으로 교체합니다.
- 브라우저 사이트 데이터 삭제, 시크릿 모드 종료, 다른 브라우저/기기 사용 시 저장 데이터가 사라지거나 공유되지 않을 수 있으므로 정기적으로 백업하세요.

## 파일 구성
- `index.html`: 앱 구조
- `style.css`: 반응형 UI 및 디자인
- `script.js`: 데이터 저장, 학습/테스트/복습 로직

## 현재 구현 메모
- 언어별로 단어와 단어장을 분리합니다. 학습 기록과 오답도 언어 ID로 구분됩니다.
- 복습 기본 간격은 1·3·7·14·30일입니다.
- 객관식 보기는 현재 언어에 등록된 다른 단어의 뜻으로 구성합니다. 오답 후보가 충분하지 않으면 입력형 문제로 전환합니다.
- 통계는 실제 학습 기록을 기반으로 계산합니다.
- LocalStorage 기반의 단일 사용자용 앱이며 기기 간 동기화 기능은 포함하지 않습니다.
